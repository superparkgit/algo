# 백준 1269 · 대칭 차집합

- 링크: https://www.acmicpc.net/problem/1269
- 학습 난이도: 집합 조회 복습
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

두 집합 중 정확히 한쪽에만 있는 원소 수를 구한다. 첫 집합을 HashSet에 저장하고 두 번째 집합을 읽으며 공통 원소 수를 센다.

정답은 |A|+|B|-2|A∩B|다. 공통 원소는 두 집합 크기에 두 번 포함되므로 두 번 빼야 한다. 각 입력이 집합이므로 내부 중복이 없다는 조건을 사용한다.

평균 시간 O(N+M), 저장 공간 O(N). 해시 조회 평균 비용에 기반한다.

## 학습 포인트와 검증

교집합·합집합·대칭 차집합을 구분한다. 결과 개수만 필요하므로 결과 원소 저장이나 정렬은 필요 없다.

- A=[1,2,4], B=[2,3] → 3
- A=[1,2], B=[1,2] → 0
- A=[1], B=[9] → 2

대표·전체 공통·공통 없음 테스트 통과. 직접 구현과 백준 제출은 사용자 과제다.
