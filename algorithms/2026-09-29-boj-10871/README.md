# X보다 작은 수

- 날짜: 2026-09-29
- 출처: 백준
- 난이도: Bronze V
- 문제 링크: https://www.acmicpc.net/problem/10871
- 상태: Java 로컬 테스트 완료

## 문제 요약

주어진 정수들을 입력 순서대로 확인해 기준값 `X`보다 작은 값만 출력한다.

## 풀이 아이디어

숫자를 하나씩 읽으면서 `number < limit` 조건을 만족하는 값만 결과 문자열에
추가한다. 입력 순서를 그대로 유지해야 하므로 정렬하지 않는다.

```java
if (number < limit) {
    result.append(number);
}
```

출력할 값이 많을 수 있으므로 매번 `System.out.print()`를 호출하는 대신
`StringBuilder`에 모아 한 번에 출력한다.

## 공백 처리

숫자 사이에만 공백이 들어가도록 결과가 비어 있지 않을 때 먼저 공백을 추가한다.

```java
if (result.length() > 0) {
    result.append(' ');
}
result.append(number);
```

이 방식은 마지막 숫자 뒤에 불필요한 공백을 남기지 않는다.

## 복잡도

- 시간 복잡도: `O(N)` — 모든 숫자를 한 번 확인한다.
- 공간 복잡도: `O(K)` — 조건을 통과한 `K`개 값을 출력 버퍼에 저장한다.

## 로컬 테스트

| 입력 특징 | 예상 출력 |
| --- | --- |
| `X=5`, 일부만 통과 | `1 4 2 3` |
| `X=0`, 음수 포함 | `-1 -2` |
| 통과하는 값 없음 | 빈 줄 |

## 직접 해볼 연습

1. `StringBuilder` 대신 배열에 결과를 저장해 본다.
2. `X`보다 큰 수만 출력하도록 조건을 변경한다.
3. `X` 이하의 값과 `X` 미만의 값이 어떻게 다른지 경계값으로 확인한다.
4. 백준에 직접 제출한 뒤 결과를 기록한다.
