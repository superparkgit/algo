# 백준 2750 · 수 정렬하기

- 링크: https://www.acmicpc.net/problem/2750
- 학습 난이도: 기초 정렬
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

정수들을 입력받아 작은 수부터 한 줄에 하나씩 출력한다. int 배열에 저장한 뒤 Arrays.sort로 오름차순 정렬한다.

일반적인 정렬 비용은 O(N log N)으로 설명하되 구체적인 알고리즘·최악 시간은 실행 JDK 구현에 의존한다. 입력 배열 공간은 O(N), 출력 버퍼는 출력 길이에 비례한다.

## 학습 포인트와 검증

Arrays.sort는 전달한 배열 자체를 변경한다. 정렬 뒤 인접 원소가 오름차순이며 원소가 빠지지 않았는지 확인한다.

- [5,2,3,4,1] → [1,2,3,4,5]
- [-1] → [-1]
- [1000,0,-1000] → [-1000,0,1000]

대표·경계 테스트 3개 통과. 직접 재작성과 백준 제출은 사용자 연습 과제다.
