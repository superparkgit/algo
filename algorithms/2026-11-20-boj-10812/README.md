# 바구니 순서 바꾸기 · 배열 구간 회전

[BOJ 10812](https://www.acmicpc.net/problem/10812)

지정 구간을 두 조각으로 나누고 뒤 조각을 앞에 붙여 회전한다. 배열 인덱스 복습용 구현 문제다.

임시 배열에 middle부터 end까지, start부터 middle 직전까지 차례대로 복사한 후 원본 구간에 덮어쓴다. 읽기와 쓰기를 분리해 아직 읽지 않은 값을 보존한다. 입력의 1부터 시작하는 번호는 즉시 0부터 시작하는 인덱스로 변환한다.

N개 바구니와 M번 연산에 최악 시간 O(NM+N), 공간 O(N). 로컬 테스트 완료. Java 컴파일 후 한 원소·연산 없음, 전체 회전, 회전 시작이 구간 앞/뒤인 경우, 연속 회전 총 5건을 확인했다. 온라인 채점 미확인.
