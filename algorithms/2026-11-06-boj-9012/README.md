# 백준 9012 · 괄호

- [문제 링크](https://www.acmicpc.net/problem/9012)
- 학습 난이도: 스택 기초 응용
- 상태: 로컬 테스트 완료. 온라인 채점 미확인.

소괄호 문자열의 모든 괄호가 올바른 순서로 짝지어졌는지 판정한다.
괄호 종류가 하나이므로 스택에 들어갈 미해결 여는 괄호를 개수로만 관리한다.
닫을 때 개수가 음수가 되면 즉시 실패한다. 끝에서는 개수가 0이어야 한다.

문자열 길이 L에 대해 시간 O(L), 판정 보조 공간 O(1)이다. 입력 문자열과 출력 버퍼는 별도다.
학습 포인트: 전체 개수뿐 아니라 처리 중인 모든 접두 구간도 검사해야 한다.
재현: javac Main.java로 컴파일한 뒤 java Main에 테스트 개수와 문자열을 입력한다.
로컬 확인: (), (()), ()()는 YES, )(, ((, ())(()는 NO.
