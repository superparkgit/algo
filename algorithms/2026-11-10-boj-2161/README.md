# 카드1 — 큐 시뮬레이션

- 문제: [BOJ 2161](https://www.acmicpc.net/problem/2161)
- 학습 난이도: 큐 입문 활용. 공식 등급은 이번 기록에서 확인하지 않았다.
- 상태: 정답을 목표로 작성한 참고 코드, 로컬 테스트 완료. 온라인 채점 미확인이며 사용자의 풀이 완료를 뜻하지 않는다.

## 직접 요약한 목표
번호 순서로 놓인 카드에서 맨 앞을 버리고, 다음 맨 앞을 맨 뒤로 옮기는 동작을 반복한다. 버린 순서를 마지막 카드까지 출력한다.

## 풀이와 학습 포인트
`ArrayDeque`의 앞을 카드 더미의 위로 정한다. `removeFirst()`로 버린 카드를 기록하고, 카드가 남았다면 `addLast(removeFirst())`로 회전한다. N=1에서는 버린 직후 비므로 두 번째 삭제를 하지 않는다. 한 회전은 남은 카드 수를 바꾸지 않으며, 각 반복은 버리기로 크기를 정확히 1 줄인다.

시간 O(N), 공간 O(N). 덱 삽입은 분할 상환 O(1)이며 출력 버퍼도 O(N)개 번호를 저장한다.

## 검증
Java 컴파일 후 직접 만든 기대값과 비교: N=1 → `1`, N=2 → `1 2`, N=4 → `1 3 2 4`, N=7 → `1 3 5 7 4 2 6`. 추가로 N=1~100을 리스트 기반 모형과 비교한다. 대역이나 외부 채점기는 사용하지 않는다.

## 직접 해볼 일
코드를 보기 전 N=5의 큐 변화를 손으로 쓰고 구현하기. 빈 큐 검사 위치를 설명한 뒤 백준에 직접 제출하기.
