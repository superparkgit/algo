# 백준 14425 · 문자열 집합

- 링크: https://www.acmicpc.net/problem/14425
- 학습 난이도: 해시 집합 입문
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

저장한 문자열 집합에 포함되는 질문 문자열의 개수를 센다. HashSet에 저장하고 질문마다 contains로 확인한다. 같은 질문이 반복되면 각 질문을 따로 센다.

해시 연산은 평균적으로 상수 시간이지만 문자열 해시·비교에는 문자열 길이 비용이 든다. 입력 문자열 처리량을 L이라 하면 평균 O(L), 저장 문자열 공간은 저장된 문자 수에 비례한다.

## 학습 포인트와 검증

횟수 저장이 필요 없으면 Map 대신 Set을 사용할 수 있다. 부분 문자열이 아닌 전체 문자열 일치를 검사한다.

- 집합 [apple,banana,pear], 질문 [apple,app,pear,grape] → 2
- 집합 [a], 질문 [a,a,b] → 2
- 집합 [cat,dog], 질문 [ca,dogs] → 0

세 로컬 테스트 통과. 직접 구현·백준 제출은 사용자 과제다.
