## 문제 요약

정수 `n`이 주어질 때, `n` 이하의 홀수를 오름차순으로 담은 배열을
반환한다.

## 예시

| n | 결과 |
|---:|---|
| 6 | `[1, 3, 5]` |
| 10 | `[1, 3, 5, 7, 9]` |
| 15 | `[1, 3, 5, 7, 9, 11, 13, 15]` |

## 풀이 아이디어

1부터 `n`까지 반복하면서 각 숫자를 2로 나눈 나머지를 확인한다.
나머지가 1이면 홀수이므로 결과 배열에 넣는다.

```text
number % 2 == 1
```

Python은 빈 리스트에 `append`로 홀수를 추가한다. Java 배열은 크기를
나중에 바꿀 수 없으므로 먼저 홀수의 개수 `(n + 1) / 2`만큼 배열을 만든 뒤,
`index` 위치에 홀수를 차례로 저장한다.

## 복잡도

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(n)` — 반환할 홀수 배열을 저장한다.

## 학습 기록

- `/`는 나눗셈이고 `%`는 나머지 연산이다.
- 홀수 판별식은 `number % 2 == 1`이다.
- 이번 코드는 정답을 보면서 학습했으므로, 다음 복습 때 힌트 없이 다시 푼다.
