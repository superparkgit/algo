# 백준 11654 · 아스키 코드

- 링크: https://www.acmicpc.net/problem/11654
- 학습 난이도: 기초 문자·형 변환
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

영문자 또는 숫자 문자 하나를 입력받아 해당 문자의 ASCII 값을 출력한다. 첫 문자를 char로 읽고 int로 변환한다. 문제의 ASCII 입력 범위에서는 Java char 값이 ASCII 코드와 같다.

시간·공간 O(1): 문제 입력은 문자 하나다.

## 학습 포인트와 로컬 검증

문자 '7'의 코드 55와 숫자 값 7은 다르다. 코드가 필요하면 int 변환, 숫자 값이 필요하면 '0'을 빼는 방식을 구별한다.

A → 65, z → 122, 0 → 48, 9 → 57의 네 입력을 확인했다. 직접 재작성·백준 제출은 사용자 연습 과제다.
