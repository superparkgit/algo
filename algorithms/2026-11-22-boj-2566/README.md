# 최댓값 · 2차원 순회 입문

[BOJ 2566](https://www.acmicpc.net/problem/2566)

9×9 표를 행 순서로 읽어 가장 큰 값과 그 위치를 찾는다. 새 최댓값을 만났을 때 값과 행·열을 함께 갱신한다. 동률이면 먼저 찾은 위치를 유지한다.

표 전체를 저장하지 않고 읽으면서 비교한다. 일반적인 R×C 표에서 시간 O(RC), 입력 한 줄의 토큰을 제외한 추가 상태는 O(1)이다.

로컬 테스트 완료. Java 컴파일 후 모두 0, 첫 칸·마지막 칸·중앙의 최대값, 전체 동률을 확인했다. 온라인 채점 미확인.
