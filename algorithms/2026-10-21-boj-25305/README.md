# 백준 25305 · 커트라인

- 링크: https://www.acmicpc.net/problem/25305
- 학습 난이도: 기초 정렬·순위 인덱스
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

N명의 점수 중 k번째로 높은 점수를 구한다. 오름차순으로 정렬하면 가장 높은 점수는 N-1, 두 번째는 N-2, k번째는 N-k 인덱스에 있다. 동점도 각각 하나의 원소로 센다.

일반적 정렬 비용 O(N log N), 입력 배열 공간 O(N). 구체적인 정렬 구현은 JDK에 의존한다.

## 학습 포인트와 검증

k는 1부터 시작하는 순위이고 인덱스는 0부터 시작한다. k=1, k=N을 대입해 N-k 식을 확인한다.

- N=5, k=2, [100,76,85,93,98] → 98
- k=1, [10,30,20] → 30
- k=N, [10,30,20] → 10
- 동점 [50,50,10], k=2 → 50

네 로컬 테스트 통과. 직접 재작성·백준 제출은 사용자 연습 과제다.
