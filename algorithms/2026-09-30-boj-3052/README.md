# 백준 3052 · 나머지

- 문제: https://www.acmicpc.net/problem/3052
- 난이도: Bronze II
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

10개의 수를 각각 42로 나눈 나머지를 구하고, 서로 다른 나머지가 몇 개인지 센다.

## 풀이 아이디어

42로 나눈 나머지는 항상 `0`부터 `41`까지다. 따라서 길이 42인 `boolean[]`을 만들고, 나머지를 배열의 인덱스로 사용한다. 처음 만난 나머지일 때만 표시하고 개수를 증가시키면 중복을 제외할 수 있다.

```text
remainder = number % 42
seen[remainder]가 false라면
  true로 바꾸고 distinctCount를 1 증가
```

## 복잡도

- 시간: `O(N)` (`N = 10`)
- 공간: `O(42)`, 고정 크기이므로 `O(1)`

## 학습 포인트

- 값의 범위가 작고 고정되어 있으면 배열 인덱스로 등장 여부를 표현할 수 있다.
- 중복 값이 들어왔을 때 개수를 다시 올리지 않도록 `false → true`가 되는 순간만 센다.
- 값의 범위를 미리 알 수 없거나 매우 넓다면 `HashSet`이 더 자연스럽다.

## 로컬 테스트

| 입력 특징 | 기대 출력 | 결과 |
|---|---:|---|
| 1부터 10까지 | 10 | 통과 |
| 42의 배수 10개 | 1 | 통과 |
| 중복 나머지가 섞인 값 | 6 | 통과 |
