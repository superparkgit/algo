# 백준 9086 · 문자열

- 링크: https://www.acmicpc.net/problem/9086
- 학습 난이도: 기초 문자열 인덱스
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

각 문자열의 첫 문자와 마지막 문자를 이어 출력한다. 첫 위치는 0, 마지막 위치는 length()-1이다. 길이 1이면 같은 문자를 두 번 출력한다.

입력 읽기 시간 O(전체 문자열 길이), 문자 접근은 케이스당 O(1). 현재 문자열과 출력 버퍼를 저장한다.

## 학습 포인트

char 두 개를 +로 바로 더하면 숫자 덧셈이 될 수 있으므로 StringBuilder에 각각 append한다. 문제는 비어 있지 않은 영문 문자열을 제공한다.

## 로컬 검증

AB → AB, A → AA, HELLO → HO, ZZZZ → ZZ. 한 실행에 4개를 넣어 줄바꿈까지 확인했다. 백준 직접 제출은 사용자 연습 과제다.
