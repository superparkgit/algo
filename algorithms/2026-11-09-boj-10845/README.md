# 백준 10845 · 큐

문제: https://www.acmicpc.net/problem/10845

학습 난이도: 큐 입문. 상태: 로컬 테스트 완료, 온라인 채점 미확인.

정수를 뒤에 넣고 앞에서 꺼내는 명령을 처리한다. ArrayDeque의 addLast와 removeFirst로 선입선출을 구현한다. front/back은 제거하지 않고 조회한다. 비었으면 요구에 따라 -1을 반환한다.

명령 N개의 총 시간 O(N), 저장 공간 O(N). 삽입은 상각 O(1)이다.
학습 포인트: 스택은 같은 끝에서 넣고 빼지만 큐는 반대 끝에서 처리한다.
로컬 검증: 빈 큐 pop/front/back, 4·7 삽입 뒤 앞=4·뒤=7, 순서대로 제거, size/empty 전환을 확인했다.
