# 백준 10807 · 개수 세기

- 링크: https://www.acmicpc.net/problem/10807
- 학습 난이도: 기초 배열·조건 누적
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 요약과 풀이

주어진 정수 목록에서 목표 정수가 등장한 횟수를 출력한다. 목표 값이 목록 뒤에 입력되므로 배열에 목록을 저장하고, 목표를 읽은 뒤 한 번 순회하며 같은 값일 때만 개수를 증가시킨다.

시간 O(N), 공간 O(N). 음수도 동등 비교로 처리하므로 배열 인덱스로 바꿀 필요가 없다.

## 학습 포인트와 검증

여러 값의 빈도와 목표 값 하나의 개수 세기를 구분한다. count는 0으로 시작하며 불일치 시 유지한다.

로컬 테스트: 혼합 목록에서 목표 2가 세 번 → 3, 목표 없음 → 0, 음수 하나가 목표와 같음 → 1, 모두 같은 값 → N. 네 테스트 통과.
