# 상수

- 날짜: 2026-09-23
- 출처: 백준
- 난이도: Bronze II
- 문제 링크: https://www.acmicpc.net/problem/2908
- 상태: Java 풀이 및 로컬 테스트 완료

## 문제 요약

세 자리 수 두 개를 입력받아 각 숫자의 자릿수를 뒤집고, 뒤집은 두 수 중
더 큰 수를 출력한다.

## 풀이 아이디어

1. 두 수를 숫자가 아닌 문자열로 입력받는다.
2. `StringBuilder.reverse()`로 각 문자열을 뒤집는다.
3. `Integer.parseInt()`로 뒤집은 문자열을 정수로 변환한다.
4. `Math.max()`로 더 큰 수를 출력한다.

문자열 상태에서 먼저 뒤집으면 일의 자리·십의 자리·백의 자리를 별도로
계산하지 않아도 된다. 숫자를 뒤집는 과정은 별도 메서드로 분리해 같은
로직을 두 번 작성하지 않았다.

## 복잡도

- 시간 복잡도: `O(n)` — 입력 문자열의 길이만큼 순회한다.
- 공간 복잡도: `O(n)` — 뒤집은 문자열을 저장한다.

이 문제에서는 문자열 길이가 3으로 고정되어 실질적인 실행 비용은 매우 작다.

## 직접 다시 써볼 부분

- `StringBuilder` 없이 반복문으로 문자열을 거꾸로 만들기
- 나눗셈과 나머지를 이용해 숫자 상태에서 뒤집기
- `reverseNumber()`가 문자열 대신 정수를 받도록 변경해 보기

## 학습 기록

- `String`은 변경할 수 없지만 `StringBuilder`는 내부 내용을 변경할 수 있다.
- `reverse()`는 같은 `StringBuilder` 객체를 뒤집어 반환한다.
- `Integer.parseInt()`는 문자열을 기본형 `int`로 변환한다.
- 백준 제출 시 패키지 선언 없이 클래스 이름을 `Main`으로 작성한다.
