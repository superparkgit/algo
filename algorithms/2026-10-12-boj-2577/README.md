# 백준 2577 · 숫자의 개수

- 링크: https://www.acmicpc.net/problem/2577
- 학습 난이도: 기초 문자열·빈도 배열
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

세 정수의 곱에 각 숫자가 몇 번 나오는지 출력한다. 곱을 문자열로 바꾼 뒤 각 문자에서 '0'을 빼 인덱스로 변환하고 해당 빈도 배열 칸을 증가시킨다.

시간 O(D + 10), 빈도 배열 공간 O(10), 문자열 공간 O(D). D는 곱의 자릿수다. 문제 최댓값 999³=997002999는 int 범위 안에 있다.

## 학습 포인트

등장 여부는 boolean, 횟수는 int 배열로 표현한다. 빈도 합은 곱의 자릿수와 같아야 한다.

## 로컬 검증

- 150×266×427 → [3,1,0,2,0,0,0,2,0,0]
- 100×100×100 → [6,1,0,0,0,0,0,0,0,0]
- 999×999×999 → [2,0,1,0,0,0,0,1,0,5]

대표·경계 테스트 3개가 기대값과 일치했다. 직접 재작성과 백준 제출은 사용자 연습 과제다.
