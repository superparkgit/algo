# 백준 10816 · 숫자 카드 2

- 링크: https://www.acmicpc.net/problem/10816
- 학습 난이도: 빈도 집계·HashMap 입문
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

보유 카드에서 각 질문 값이 몇 번 등장하는지 출력한다. HashMap의 키에 카드 값, 값에 등장 횟수를 저장한다. 입력마다 기존 횟수에 1을 더하고 없는 질문은 0으로 출력한다.

평균 시간 O(N+M), 빈도 저장 공간 O(U), 출력 버퍼 O(M). U는 서로 다른 카드 수다. 해시 연산의 평균 시간에 기반한 설명이다.

## 학습 포인트와 검증

존재 여부만 반환하는 이진 탐색으로는 개수를 바로 알 수 없다. 음수·큰 범위 값을 직접 배열 인덱스로 쓰지 않고 키로 관리한다.

- [6,3,2,10,10,10,-10,-10,7,3], 질문 [10,9,-5,2,3,4,5,-10] → 3 0 0 1 2 0 0 2
- [0], 질문 [0,1,-1] → 1 0 0
- [5,5,5,5], 질문 [5,5,6] → 4 4 0

로컬 테스트 3개 통과. 질문은 조회이므로 같은 질문을 반복해도 횟수가 줄지 않는다. 직접 제출은 사용자 과제다.
