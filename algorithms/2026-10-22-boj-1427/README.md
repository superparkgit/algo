# 백준 1427 · 소트인사이드

- 링크: https://www.acmicpc.net/problem/1427
- 학습 난이도: 기초 문자 배열·정렬
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

입력 수의 각 자릿수를 큰 숫자부터 배치한다. 입력을 문자 배열로 바꾸고 오름차순 정렬한 뒤 마지막 인덱스부터 역순으로 출력한다.

숫자 문자 '0'~'9'는 코드 순서와 숫자 크기 순서가 같아 문자 정렬을 사용할 수 있다. 숫자 전체를 정수로 파싱할 필요가 없다.

일반적 정렬 비용 O(D log D), 저장 공간 O(D). D는 자릿수이며 구체적 정렬 구현은 JDK에 의존한다.

## 학습 포인트와 검증

정렬 방향과 출력 방향은 별개다. 역순 반복의 시작은 length-1, 끝은 0을 포함한다.

2143 → 4321, 1000 → 1000, 7 → 7, 909090 → 999000. 로컬 테스트 4개 통과. 직접 재작성·백준 제출은 사용자 연습 과제다.
