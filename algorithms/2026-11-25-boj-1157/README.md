# 단어 공부 · 빈도 배열 복습

[BOJ 1157](https://www.acmicpc.net/problem/1157)

영문 대소문자를 같은 문자로 집계해 가장 자주 나온 대문자를 출력한다. 최다 빈도가 같으면 물음표를 출력한다. 학습 난이도는 문자열·빈도 배열 입문이다.

문자를 대문자로 바꾸고 A와의 차이를 0~25 인덱스로 사용한다. 집계 후 빈도 배열을 순회한다. 더 큰 빈도를 만나면 답을 새 문자로 바꾸고 동률이면 물음표로 바꾼다. 앞선 동률 뒤 더 큰 빈도가 등장하는 경우도 처리한다.

문자열 길이 N에 시간 O(N+26), 입력 문자열 O(N), 집계 배열 추가 공간 O(26).

로컬 테스트 완료. Java 컴파일 후 단일 문자, 대소문자 혼합, 동률, 동률 후 최댓값 재갱신, Z 경계, 100만 문자 총 6건을 검증했다. 온라인 채점 미확인.
