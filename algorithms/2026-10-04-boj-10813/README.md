# 백준 10813 · 공 바꾸기

- 문제: https://www.acmicpc.net/problem/10813
- 난이도: Bronze II
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

1번부터 N번까지 바구니에 처음에는 바구니 번호와 같은 공이 들어 있다. 두 바구니 번호가 주어질 때마다 공의 위치를 서로 바꾸고, 모든 교환 후의 배치를 출력한다.

## 풀이 아이디어

길이 N + 1인 배열을 만들고 각 바구니에 자신의 번호를 넣어 초기화한다. 두 위치를 바꿀 때 첫 번째 값을 임시 변수에 보관한 다음 두 번째 값을 첫 번째 위치로, 임시 값을 두 번째 위치로 옮긴다.

임시 변수 없이 첫 번째 위치부터 덮어쓰면 기존 값 하나를 잃게 된다.

## 복잡도

- 시간: 초기화 O(N), 교환 O(M), 출력 O(N)이므로 전체 O(N + M)
- 공간: O(N)

## 학습 포인트

- 두 값을 교환할 때 임시 변수가 필요한 이유를 이해한다.
- 같은 위치끼리 교환해도 배열은 변하지 않는다.
- 교환은 값의 위치만 바꾸므로 원소의 종류와 개수는 유지된다.
- 명령을 입력 순서대로 적용해야 최종 배치가 맞는다.

## 로컬 테스트

| 입력 특징 | 기대 출력 | 결과 |
|---|---|---|
| 여러 위치를 연속 교환 | 3 1 4 2 5 | 통과 |
| 같은 위치끼리 교환 | 1 2 3 | 통과 |
| 같은 두 위치를 두 번 교환 | 1 2 3 4 | 통과 |
