# 피자 나눠 먹기 (1)

- 날짜: 2026-09-18
- 출처: 프로그래머스
- 난이도: Lv. 0
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/120814
- 상태: 정답 학습 완료

## 문제 요약

피자 한 판은 7조각이다. 사람 수 `n`이 주어질 때, 모든 사람이 최소 한
조각씩 먹기 위해 필요한 최소 피자 판 수를 반환한다.

## 예시 확인

| n | 필요한 피자 수 | 이유 |
|---:|---:|---|
| 7 | 1 | 7조각이면 정확히 한 명당 한 조각이다. |
| 8 | 2 | 한 판의 7조각으로는 한 조각이 부족하다. |
| 14 | 2 | 두 판은 14조각이다. |

## 나의 풀이 아이디어

`n`을 7로 나눈 몫과 나머지를 구한다.

- 나머지가 0이면 몫만큼의 피자가 필요하다.
- 나머지가 0이 아니면 남은 사람을 위해 피자 한 판을 추가한다.

## 복잡도

- 시간 복잡도: `O(1)`
- 공간 복잡도: `O(1)`
