# 그룹 단어 체커 · 문자열 상태 관리 입문

[BOJ 1316](https://www.acmicpc.net/problem/1316)

각 문자가 한 덩어리로만 등장하는 단어의 개수를 센다. 직전 문자와 현재 문자가 다를 때만 새 덩어리 시작으로 판단한다. 이미 본 문자가 새 덩어리로 시작하면 조건을 위반한다.

단어마다 boolean 방문 배열과 직전 문자를 초기화한다. 전체 문자 수 S에 시간 O(S), 단어 입력 문자열 외 추가 공간 O(26).

로컬 테스트 완료. Java 컴파일 후 한 글자, 같은 문자 연속, 끊긴 뒤 재등장, 혼합 단어, 단어별 상태 초기화를 검증했다. 온라인 채점 미확인.
