# 백준 1546 · 평균

- 문제: https://www.acmicpc.net/problem/1546
- 난이도: Bronze I
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

가장 높은 점수를 M이라고 할 때 각 점수를 점수/M×100으로 바꾼다. 바뀐 점수들의 평균을 구한다.

## 풀이 아이디어

입력을 한 번 순회하며 원래 점수의 합과 최댓값을 함께 구한다. 바뀐 점수를 하나씩 저장하지 않아도 다음 식으로 평균을 계산할 수 있다.

바뀐 평균 = 원래 점수 합 / 최댓값 × 100 / 과목 수

합계를 double로 저장해 첫 나눗셈부터 실수 연산이 되도록 한다.

## 복잡도

- 시간: O(N)
- 추가 공간: O(1)

## 학습 포인트

- 필요한 결과가 합계와 최댓값만으로 계산되는지 먼저 식을 정리한다.
- 정수끼리 나누면 소수 부분이 사라지므로 double 연산을 보장한다.
- 모든 변환 값을 배열에 저장하지 않고도 평균을 구할 수 있다.
- 계산 순서를 간단한 예로 확인해 정수 나눗셈 실수를 예방한다.

## 로컬 테스트

| 입력 특징 | 기대 출력 | 결과 |
|---|---:|---|
| 40, 80, 60 | 75.0 | 통과 |
| 과목 하나, 점수 100 | 100.0 | 통과 |
| 1, 2, 4, 8 | 46.875 | 통과 |
