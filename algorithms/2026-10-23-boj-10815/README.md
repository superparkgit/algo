# 백준 10815 · 숫자 카드

- 링크: https://www.acmicpc.net/problem/10815
- 학습 난이도: 정렬 기초 다음 단계, 이진 탐색 입문
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

보유 카드 목록에 각 질문 값이 있으면 1, 없으면 0을 출력한다. 카드를 정렬하고 각 값을 이진 탐색한다. 가운데 값보다 목표가 크면 오른쪽, 작으면 왼쪽만 남긴다.

닫힌 구간 [left,right]를 사용한다. 가운데 값을 검사한 뒤 다음 구간에서 제외해야 탐색 범위가 줄어든다.

일반적 정렬 비용 O(N log N), 질문 처리 O(M log N), 카드 배열 O(N), 출력 버퍼 O(M).

## 학습 포인트와 검증

정렬이 탐색 구간 절반을 버릴 수 있는 근거다. 순차 탐색과 같은 작은 입력 결과를 먼저 확인한다.

- 카드 [6,3,2,10,-10], 질문 [10,9,-5,2,3,4,5,-10] → 1 0 0 1 1 0 0 1
- 카드 [0], 질문 [-1,0,1] → 0 1 0
- 카드 [-10000000,10000000], 질문 [10000000,-10000000,0] → 1 1 0

세 로컬 테스트 통과. 온라인 제출·직접 구현은 사용자 과제다.
