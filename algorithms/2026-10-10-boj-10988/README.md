# 백준 10988 · 팰린드롬인지 확인하기

- 문제: https://www.acmicpc.net/problem/10988
- 학습 난이도: 기초 문자열·두 포인터
- 상태: Java 로컬 테스트 완료. 온라인 제출 여부 미확인.

## 요약과 풀이

단어를 앞뒤로 읽은 결과가 같으면 1, 다르면 0을 출력한다. 양끝 문자를 비교하며 왼쪽 위치는 증가시키고 오른쪽 위치는 감소시킨다. 한 쌍이라도 다르면 즉시 종료한다. 가운데 문자는 비교하지 않아도 된다.

시간 O(L), 추가 공간 O(1). L은 문자열 길이다.

## 학습 포인트

양끝 비교, 조기 종료, 길이 1과 홀수·짝수 경계를 익힌다. 한 쌍의 일치만으로 회문을 확정할 수는 없지만 불일치 하나로는 반박할 수 있다.

## 검증

level → 1, abba → 1, a → 1, abca → 0, abc → 0.
5개 입력을 로컬에서 확인했다. 백준 직접 제출은 사용자 연습 과제다.
