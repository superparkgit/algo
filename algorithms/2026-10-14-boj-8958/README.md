# 백준 8958 · OX퀴즈

- 문제 링크: https://www.acmicpc.net/problem/8958
- 학습 난이도: 기초 문자열·상태 누적
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

O가 연속으로 나오면 점수가 1, 2, 3처럼 증가하고 X를 만나면 연속 점수가 끊긴다. 각 문자열의 총점을 출력한다.

streak는 현재 연속 O 개수, total은 누적 총점이다. O이면 streak를 늘려 total에 더하고 X이면 streak만 0으로 만든다. 테스트 케이스마다 두 변수를 새로 초기화한다.

시간 O(전체 입력 문자 수), 출력 버퍼 공간 O(출력 길이). 현재 문자열 저장 공간 O(L).

## 학습 포인트와 로컬 검증

현재 상태와 누적 결과의 역할을 구분한다. X에서 total까지 지우면 이전 점수가 사라진다.

- OOXXOXXOOO → 10
- XXXX → 0
- O → 1
- OOOO → 10
- OXOXO → 3

한 실행에 다섯 케이스를 넣어 케이스 간 상태 초기화도 확인했다. 직접 재작성·백준 제출은 사용자 과제다.
