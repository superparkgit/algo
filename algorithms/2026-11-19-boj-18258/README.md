# 큐 2 · 대량 입력 복습

[BOJ 18258](https://www.acmicpc.net/problem/18258)

명령에 따라 정수를 큐에 넣거나 꺼내고 조회 결과를 출력한다. 학습 난이도는 큐 기본 구현 복습이다. 기존 10845 풀이를 재사용해 더 큰 입력에서 검증했다.

ArrayDeque의 뒤에 추가하고 앞에서 제거해 FIFO를 지킨다. 빈 큐에서 조회·제거 요청을 받으면 -1을 출력한다. BufferedReader로 읽고 StringBuilder에 출력 결과를 모아 한 번에 출력한다.

명령 N개에 분할 상환 O(N) 시간과 O(N) 공간을 사용한다. 출력 문자열도 결과 개수에 비례한다.

로컬 테스트 완료. 빈 큐와 두 원소의 순서를 포함하는 12개 명령, 삽입 100만 번과 제거 100만 번을 검증했다. 온라인 채점 미확인.
