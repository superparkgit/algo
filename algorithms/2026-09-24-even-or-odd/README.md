## 문제 요약

정수 `num`이 짝수이면 `"Even"`, 홀수이면 `"Odd"`를 반환한다.
`0`도 짝수로 처리한다.

## 예시

| num | 결과 |
|---:|---|
| 3 | `"Odd"` |
| 4 | `"Even"` |
| 0 | `"Even"` |

## 풀이 아이디어

숫자를 2로 나눈 나머지가 0이면 짝수이고, 그렇지 않으면 홀수다.

```text
num % 2 == 0  → 짝수
그렇지 않음   → 홀수
```

Python과 Java 모두 같은 조건식을 사용한다. 반환하는 문자열도 문제에서
요구한 대소문자 그대로 `"Even"`, `"Odd"`라고 작성해야 한다.

## 복잡도

- 시간 복잡도: `O(1)`
- 공간 복잡도: `O(1)`

## 학습 기록

- `/`는 나눗셈, `%`는 나머지 연산이다.
- `if`와 `else`를 이용해 짝수와 홀수를 구분할 수 있다.
- `0 % 2`도 0이므로 0은 짝수다.
