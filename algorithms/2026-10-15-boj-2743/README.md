# 백준 2743 · 단어 길이 재기

- 링크: https://www.acmicpc.net/problem/2743
- 학습 난이도: 기초 문자열 문법
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

영문 단어를 입력받아 길이를 출력한다. String.length()를 호출한다. 입력이 영어 알파벳이므로 UTF-16 코드 단위 수와 문자 수가 일치한다.

입력 읽기 시간 O(L), length() 호출 O(1), 문자열 저장 공간 O(L).

## 학습 포인트와 검증

배열은 length 필드, 문자열은 length() 메서드다. 필요하지 않은 반복문을 추가하지 않는다.

로컬 테스트: A → 1, OpenAI → 6, 영문자 100개 → 100. 직접 재작성과 백준 제출은 사용자 과제다.
