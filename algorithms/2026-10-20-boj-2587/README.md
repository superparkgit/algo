# 백준 2587 · 대표값2

- 링크: https://www.acmicpc.net/problem/2587
- 학습 난이도: 기초 정렬·집계
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

정수 다섯 개의 평균과 중앙값을 차례로 출력한다. 입력 중 합계를 구하고 배열을 정렬한 뒤 가운데 인덱스 2의 값을 읽는다.

평균은 합/개수, 중앙값은 정렬했을 때 가운데 값이다. 문제 입력은 10의 배수 다섯 개이므로 평균을 정수 나눗셈으로 구해도 정확하다. 일반 평균 계산에는 실수 변환이 필요할 수 있다.

일반화하면 정렬 시간 O(N log N), 배열 공간 O(N). 이 문제는 N=5로 고정이다.

## 학습 포인트와 로컬 검증

정렬 전 인덱스 2의 값은 중앙값을 보장하지 않는다. 중복 값도 정렬 결과에 그대로 포함한다.

- [10,40,30,60,30] → 평균 34, 중앙값 30
- [10,10,10,10,10] → 10, 10
- [90,10,20,30,40] → 38, 30

대표·중복·순서 경계 테스트 3개 통과. 직접 재작성·백준 제출은 사용자 과제다.
