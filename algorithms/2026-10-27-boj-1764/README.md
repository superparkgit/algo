# 백준 1764 · 듣보잡

- 링크: https://www.acmicpc.net/problem/1764
- 학습 난이도: 집합 조회와 정렬 복습
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

두 이름 목록에 공통으로 있는 이름의 개수와 사전순 목록을 출력한다. 첫 목록을 HashSet에 저장하고 두 번째 목록을 읽으며 공통 이름을 ArrayList에 모은 뒤 정렬한다. 각 입력 목록에 같은 이름이 반복되지 않는 문제 조건을 사용한다.

문자열 길이 상한을 B, 공통 원소 수를 K라 하면 평균 시간 O((N+M)B + K log K × B), 저장 공간은 이름 문자열과 결과 목록에 비례한다.

## 학습 포인트와 검증

HashSet은 순서를 보장하지 않는다. 존재 확인과 출력 정렬을 분리한다.

- 첫 [zoe,amy,bob], 둘째 [bob,zoe,kai] → 2 / bob / zoe
- 공통 이름 없음 → 0만 출력
- 첫·둘째 모두 [amy] → 1 / amy

세 로컬 테스트 통과. 직접 구현·백준 제출은 사용자 과제다.
