# 백준 1152 · 단어의 개수

- 링크: https://www.acmicpc.net/problem/1152
- 학습 난이도: 기초 문자열 순회
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

공백으로 구분된 영어 문장의 단어 수를 구한다. 문장 앞뒤 공백은 단어가 아니다.

문자열을 순회하며 현재 단어 안에 있는지를 boolean으로 저장한다. 공백이면 단어 밖으로 이동하고, 단어 밖에서 문자를 처음 만났을 때만 개수를 증가시킨다. 연속 공백도 추가 단어로 세지 않는다.

시간 O(L), 추가 공간 O(1). 입력 문자열 저장까지 포함하면 공간 O(L).

## 학습 포인트와 테스트

단어의 모든 문자를 세는 대신 '단어 시작' 사건을 센다. readLine으로 문장 전체와 공백을 읽는다.

로컬 테스트: The Curious Cat → 3, 앞뒤 공백의 hello world → 2, A → 1, 공백만 있는 입력 → 0, 연속 공백의 a b c → 3. 마지막 두 경우는 구분자 처리의 추가 방어 테스트다.
