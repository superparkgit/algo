# 백준 10828 · 스택

문제: https://www.acmicpc.net/problem/10828

난이도: 스택 입문. 상태: 로컬 테스트 완료, 온라인 채점 미확인.

## 요약과 풀이

정수를 넣고 마지막에 넣은 값을 조회·제거하는 명령을 처리한다. ArrayDeque의 push, peek, pop으로 후입선출을 구현한다. 빈 스택에서는 문제에서 요구한 -1을 반환하도록 먼저 검사한다.

N개 명령의 총 시간 O(N), 저장 공간 O(N). push는 상각 O(1)이다.

## 학습 포인트·검증

peek는 조회, pop은 조회와 제거다. 정상 push/pop 순서, 빈 스택의 pop/top, size/empty와 반복 top을 로컬에서 검증했다. 사용자 직접 구현·제출은 아직 미확인이다.
