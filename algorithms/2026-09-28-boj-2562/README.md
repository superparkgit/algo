# 최댓값

- 날짜: 2026-09-28
- 출처: 백준
- 난이도: Bronze III
- 문제 링크: https://www.acmicpc.net/problem/2562
- 상태: Java 로컬 테스트 완료

## 문제 요약

아홉 개의 자연수를 순서대로 확인해 최댓값과 그 값이 입력된 위치를 출력한다.

## 풀이 아이디어

숫자를 읽을 때마다 현재 최댓값과 비교한다. 더 큰 값을 만나면 최댓값뿐 아니라
현재 위치도 함께 갱신한다.

```java
if (number > maximum) {
    maximum = number;
    maximumPosition = position;
}
```

문제의 위치는 1부터 시작하므로 반복문의 `position`도 1부터 시작했다. 배열을
만들거나 입력을 정렬할 필요 없이 두 변수만 유지하면 된다.

## `>`와 `>=`의 차이

- `>`를 사용하면 같은 최댓값이 다시 나와도 처음 위치를 유지한다.
- `>=`를 사용하면 같은 최댓값이 나올 때마다 마지막 위치로 갱신된다.

이 문제에서는 서로 다른 자연수가 주어지지만, 일반적인 위치 추적 문제에서는
동점 처리 기준을 먼저 결정해야 한다.

## 복잡도

- 시간 복잡도: `O(N)` — 모든 숫자를 한 번 확인한다.
- 공간 복잡도: `O(1)` — 최댓값과 위치만 저장한다.

## 로컬 테스트

| 입력 특징 | 예상 최댓값 | 예상 위치 |
| --- | ---: | ---: |
| 예제 입력 | 85 | 8 |
| 모든 값이 1 | 1 | 1 |
| 마지막 값이 100 | 100 | 9 |

## 직접 해볼 연습

1. 배열에 입력을 저장한 뒤 최댓값의 위치를 찾는 방식으로 다시 구현한다.
2. `>`를 `>=`로 바꾸고 중복 최댓값 입력에서 결과를 비교한다.
3. 최솟값과 그 위치도 함께 출력하도록 확장한다.
4. 백준에 직접 제출한 뒤 결과를 기록한다.
