# 백준 5597 · 과제 안 내신 분..?

- 문제: https://www.acmicpc.net/problem/5597
- 난이도: Bronze III
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

1번부터 30번까지 학생 중 과제를 제출한 28명의 번호가 주어진다. 제출하지 않은 두 학생의 번호를 작은 순서부터 출력한다.

## 풀이 아이디어

학생 번호를 인덱스로 쓰는 길이 31의 boolean 배열을 준비한다.

1. 입력받은 번호의 값을 true로 표시한다.
2. 1번부터 30번까지 다시 순회한다.
3. 값이 false인 인덱스를 출력한다.

전체 범위를 오름차순으로 확인하기 때문에 별도의 정렬 없이 작은 번호부터 출력된다. 인덱스 0은 학생 번호로 사용하지 않는다.

## 복잡도

- 시간: O(N + M) (N = 28, M = 30)
- 공간: O(31), 고정 크기이므로 O(1)

## 학습 포인트

- 입력을 읽는 순회와 결과를 찾는 순회의 역할을 분리한다.
- boolean 배열의 기본값 false를 '아직 제출하지 않음'이라는 상태로 활용한다.
- 가능한 값을 오름차순으로 순회하면 결과 정렬을 따로 하지 않아도 된다.

## 로컬 테스트

| 입력 특징 | 기대 출력 | 결과 |
|---|---|---|
| 1, 2번만 누락 | 1, 2 | 통과 |
| 15, 30번 누락 | 15, 30 | 통과 |
| 7, 21번 누락·입력 순서 혼합 | 7, 21 | 통과 |
