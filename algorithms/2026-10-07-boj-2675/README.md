# 백준 2675 · 문자열 반복

- 문제: https://www.acmicpc.net/problem/2675
- 난이도: Bronze II
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

반복 횟수 R과 문자열 S가 주어진다. S의 각 문자를 R번씩 연속으로 반복한 새 문자열을 테스트 케이스마다 출력한다.

## 풀이 아이디어

문자열을 왼쪽부터 한 글자씩 순회한다. 현재 문자를 repeatCount번 StringBuilder에 추가한 뒤 다음 문자로 이동한다. 모든 테스트 케이스의 출력을 하나의 버퍼에 모아 마지막에 한 번 출력한다.

문자열 전체를 여러 번 복제하는 것이 아니라 각 문자를 연속으로 반복해야 한다.

## 복잡도

- 테스트 케이스 하나의 시간: O(문자열 길이 × 반복 횟수)
- 출력 결과를 저장하는 공간: O(생성되는 전체 문자열 길이)

## 학습 포인트

- length로 문자열 길이를 확인하고 charAt으로 각 문자에 접근한다.
- 바깥 반복문은 문자 위치, 안쪽 반복문은 같은 문자의 반복 횟수를 담당한다.
- StringBuilder로 반복적인 문자열 결합 비용을 줄인다.
- 테스트 케이스마다 줄바꿈을 추가한다.

## 로컬 테스트

| 입력 특징 | 기대 출력 | 결과 |
|---|---|---|
| 영문자와 기호가 포함된 두 테스트 | 각 문자 3회·5회 반복 | 통과 |
| 반복 횟수 1 | 원문 유지 | 통과 |
| 한 글자를 8회 반복 | 같은 문자 8개 | 통과 |
