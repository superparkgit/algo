# 백준 10810 · 공 넣기

- 문제: https://www.acmicpc.net/problem/10810
- 난이도: Bronze III
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

1번부터 N번까지 바구니가 있다. 각 명령은 시작 바구니부터 끝 바구니까지 같은 번호의 공을 넣는다. 이미 공이 있다면 새 번호로 바뀐다. 모든 명령이 끝난 뒤 각 바구니의 공 번호를 출력한다.

## 풀이 아이디어

바구니 번호와 배열 인덱스를 맞추기 위해 길이가 N + 1인 int 배열을 만든다. 각 명령마다 시작부터 끝까지 순회하며 공 번호를 대입한다.

대입은 기존 값을 새 값으로 덮어쓰므로 명령 순서도 자연스럽게 반영된다. 한 번도 선택되지 않은 바구니는 int 배열의 기본값 0을 유지한다.

## 복잡도

- 시간: 최악의 경우 O(N × M)
- 공간: O(N)

제한이 작기 때문에 각 구간을 직접 순회해도 충분하다.

## 학습 포인트

- 문제의 번호가 1부터 시작할 때 N + 1 크기 배열을 활용할 수 있다.
- 끝 바구니도 포함하므로 반복 조건은 basket &lt;= end이다.
- 새 명령이 이전 상태를 덮어쓰는지, 누적하는지 문제 문장에서 구분해야 한다.
- 여러 값을 한 줄에 출력할 때 StringBuilder를 사용할 수 있다.
