# 최소, 최대

- 날짜: 2026-09-26
- 출처: 백준
- 난이도: Bronze III
- 문제 링크: https://www.acmicpc.net/problem/10818
- 상태: Java 로컬 테스트 완료

## 문제 요약

주어진 정수들을 한 번씩 확인해 가장 작은 값과 가장 큰 값을 출력한다.

## 풀이 아이디어

입력값을 순서대로 읽으며 지금까지의 최솟값과 최댓값을 갱신한다. 모든 값을
저장한 뒤 정렬할 필요가 없고, 한 번의 순회만으로 답을 구할 수 있다.

```java
minimum = Math.min(minimum, number);
maximum = Math.max(maximum, number);
```

초깃값은 입력 범위에 포함되는 임의의 숫자보다 `Integer.MAX_VALUE`와
`Integer.MIN_VALUE`를 사용하는 편이 안전하다. 첫 번째 입력값으로 두 변수를
초기화하는 방법도 가능하다.

## 복잡도

- 시간 복잡도: `O(N)` — 모든 숫자를 한 번 확인한다.
- 공간 복잡도: `O(1)` — 입력 배열을 따로 저장하지 않는다.

정렬을 사용하면 일반적으로 `O(N log N)`이 필요하므로 최솟값과 최댓값만
필요한 문제에서는 한 번의 순회가 더 적합하다.

## 경계 조건

- 입력이 한 개인 경우에는 최솟값과 최댓값이 같다.
- 모든 숫자가 음수여도 정상적으로 비교해야 한다.
- 같은 최솟값이나 최댓값이 여러 번 나올 수 있다.

## 로컬 테스트

| 입력 개수 | 숫자 | 예상 출력 |
| ---: | --- | --- |
| 1 | `7` | `7 7` |
| 5 | `20 10 35 30 7` | `7 35` |
| 4 | `-5 -1 -9 -3` | `-9 -1` |

## 직접 해볼 연습

1. `Math.min()`과 `Math.max()` 없이 `if`문으로 다시 작성한다.
2. 첫 번째 숫자로 최솟값과 최댓값을 초기화해 본다.
3. 입력값을 배열에 저장하는 풀이와 현재 풀이의 공간 복잡도를 비교한다.
4. 백준에 직접 제출하고 결과를 기록한다.
