# 숫자의 합

- 날짜: 2026-09-25
- 출처: 백준
- 난이도: Bronze IV
- 문제 링크: https://www.acmicpc.net/problem/11720
- 상태: Java 로컬 테스트 완료

## 문제 요약

숫자의 개수와 이어진 숫자 문자열을 입력받아 각 자리 숫자의 합을 출력한다.

## 풀이 아이디어

입력값 전체가 `int`나 `long`의 범위를 넘을 수 있으므로 숫자 문자열을 하나의
정수로 변환하지 않는다. 문자열을 처음부터 순회하면서 각 문자를 숫자로 바꿔
합계에 더한다.

Java에서 숫자 문자는 문자 코드상 연속되어 있다. 따라서 다음 연산으로
`'0'`부터 떨어진 거리를 구하면 실제 숫자값이 된다.

```java
int digit = digits.charAt(index) - '0';
```

예를 들어 `'7' - '0'`의 결과는 `7`이다.

## 복잡도

- 시간 복잡도: `O(N)` — 숫자 문자를 한 번씩 확인한다.
- 공간 복잡도: `O(N)` — 입력 숫자를 문자열로 저장한다.

## 경계 조건

- 숫자가 한 자리뿐인 경우
- 모든 자리가 `0`인 경우
- 숫자 문자열이 기본 정수형 범위를 넘는 경우

문자열로 처리하므로 전체 숫자의 크기와 관계없이 각 자리의 합을 계산할 수 있다.

## 로컬 테스트

| N | 숫자 문자열 | 예상 출력 |
| ---: | --- | ---: |
| 1 | `0` | 0 |
| 5 | `54321` | 15 |
| 25 | `7000000000000000000000000` | 7 |

## 직접 해볼 연습

1. 현재 코드를 보지 않고 `charAt()`과 `'0'`을 사용해 다시 작성한다.
2. `Character.getNumericValue()`를 사용한 풀이와 비교한다.
3. 숫자 이외의 문자가 입력되면 어떻게 검증할지 생각해본다.
4. 백준에 직접 제출한 뒤 결과를 기록한다.
