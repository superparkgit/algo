# BOJ 10866 덱

[문제 링크](https://www.acmicpc.net/problem/10866)

자료구조 입문. 정수를 양 끝에 넣고 꺼내며, 각 조회와 제거 결과를 출력한다.

ArrayDeque의 First와 Last를 각 명령에 대응시킨다. peek는 값을 유지하고 poll은 제거한다. 빈 덱에서 두 연산이 반환하는 null을 출력 단계에서 -1로 바꾼다.

명령 N개에 분할 상환 O(N) 시간, 덱과 출력 버퍼에 O(N) 공간을 사용한다.

로컬 테스트 완료. Java 컴파일과 빈 덱, 원소 하나, 양쪽 조작 혼합 입력을 확인했다. 온라인 채점 미확인.
