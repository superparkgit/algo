# 색종이 · 격자 표시 입문 응용

[BOJ 2563](https://www.acmicpc.net/problem/2563)

한 변이 10인 정사각형들이 덮은 격자 칸 수를 구한다. boolean 배열에 덮은 칸을 표시하고 처음 덮는 칸에서만 넓이를 증가시킨다. 중복 영역을 여러 번 세지 않는 것이 학습 포인트다.

왼쪽 좌표부터 10칸을 반열린 구간으로 순회한다. 색종이 N장에 시간 O(100N), 고정 100×100 배열 공간을 사용한다.

로컬 테스트 완료. Java 컴파일 후 단일·완전중복·부분중복·변만 맞닿음·오른쪽 위 경계를 검증했다. 온라인 채점 미확인.
