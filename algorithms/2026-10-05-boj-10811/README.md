# 백준 10811 · 바구니 뒤집기

- 문제: https://www.acmicpc.net/problem/10811
- 난이도: Bronze II
- 언어: Java
- 상태: 로컬 테스트 완료 (온라인 제출 여부 미확인)

## 문제 요약

1번부터 N번까지 바구니가 순서대로 놓여 있다. 각 명령에서 주어진 시작 위치부터 끝 위치까지의 바구니 순서를 뒤집고, 모든 명령 후의 배치를 출력한다.

## 풀이 아이디어

뒤집을 구간의 양끝을 left와 right로 잡는다. 두 위치의 값을 교환한 뒤 left는 오른쪽으로, right는 왼쪽으로 이동한다. 두 포인터가 만나거나 엇갈리면 해당 구간 뒤집기가 끝난다.

구간 길이가 홀수이면 가운데 값은 자기 자리에 남으므로 교환할 필요가 없다.

## 복잡도

- 초기화와 출력: O(N)
- 각 명령: 뒤집는 구간 길이에 비례
- 전체: O(N + 모든 뒤집기 구간 길이의 합)
- 공간: O(N)

## 학습 포인트

- 양끝에서 가운데로 이동하는 두 포인터 방식을 이해한다.
- 반복 조건을 left &lt; right로 두어 불필요한 자기 자신 교환을 피한다.
- 부분 구간만 뒤집고 범위 밖의 원소는 그대로 유지한다.
- 같은 구간을 두 번 뒤집으면 원래 상태로 돌아온다.

## 로컬 테스트

| 입력 특징 | 기대 출력 | 결과 |
|---|---|---|
| 여러 부분 구간을 연속으로 뒤집기 | 3 4 1 2 5 | 통과 |
| 전체 홀수 길이 구간 뒤집기 | 5 4 3 2 1 | 통과 |
| 가운데를 포함한 짝수 길이 부분 구간 | 1 5 4 3 2 6 | 통과 |
