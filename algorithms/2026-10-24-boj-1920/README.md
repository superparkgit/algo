# 백준 1920 · 수 찾기

- 링크: https://www.acmicpc.net/problem/1920
- 학습 난이도: 이진 탐색 복습
- 상태: Java 로컬 테스트 완료. 온라인 채점 미확인.

## 직접 작성한 요약과 풀이

목록에 각 질문 값이 존재하는지 한 줄씩 출력한다. 배열을 먼저 정렬하고 Arrays.binarySearch의 반환값이 0 이상이면 존재한다고 판단한다.

어제는 직접 탐색 구간을 구현했고, 오늘은 표준 메서드의 반환 규칙을 확인한다. 인덱스 0도 찾은 결과이므로 조건을 0 초과로 쓰면 틀린다.

일반적인 정렬 비용 O(N log N), 질문 O(M log N), 배열 공간 O(N), 출력 버퍼 O(M). 정렬 구현 세부는 JDK에 의존한다.

## 로컬 검증

- [4,1,5,2,3], 질문 [1,3,7,9,5] → 1 1 0 0 1
- [0], 질문 [-1,0,1] → 0 1 0
- [-2147483648,0,2147483647], 같은 양끝과 없는 1 질문 → 1 1 0

세 테스트 통과. 줄바꿈 출력과 int 양끝도 확인했다. 직접 제출은 사용자 과제다.
