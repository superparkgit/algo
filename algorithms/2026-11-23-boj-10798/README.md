# 세로읽기 · 문자열 순회 입문

[BOJ 10798](https://www.acmicpc.net/problem/10798)

다섯 문자열을 열 순서로 순회하며 존재하는 문자만 이어 붙인다. 각 행 길이가 다를 수 있으므로 charAt 전에 현재 열이 해당 행 길이보다 작은지 확인한다.

열 반복을 바깥에, 행 반복을 안에 두면 세로 순서가 된다. 행 R개, 최대 길이 L에서 시간 O(RL), 입력·출력 공간 O(RL).

로컬 테스트 완료. Java 컴파일 후 길이 1, 행마다 다른 길이, 동일 길이 입력을 확인했다. 온라인 채점 미확인.
