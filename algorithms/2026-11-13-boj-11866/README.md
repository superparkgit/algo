# BOJ 11866 요세푸스 문제 0

[문제 링크](https://www.acmicpc.net/problem/11866)

원형으로 배치한 사람을 K명씩 세어 한 명씩 제외하고, 제외 순서를 출력한다. 큐 회전을 복습하는 입문 응용 문제다.

앞 사람을 뒤로 보내는 동작을 K-1번 한 뒤 앞 사람을 제거한다. 현재 큐 크기만큼 회전하면 원래 순서로 돌아오므로 실제 회전 횟수는 (K-1) % 현재 크기다. K=1이면 회전 없이 앞에서부터 제거한다. StringJoiner로 숫자 사이의 구분자와 양 끝 괄호를 붙인다.

덱 연산 기준 최악 시간 O(NK), 큐 공간 O(N). 문자열 출력과 버퍼 비용은 출력 길이에 비례한다.

로컬 테스트 완료. Java 컴파일 후 N=1, K=1인 경우, K=1인 여러 명, K=N인 경우와 일반 입력을 확인했다. 온라인 채점은 미확인이다.
