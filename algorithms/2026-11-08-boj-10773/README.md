# 백준 10773 · 제로

문제: https://www.acmicpc.net/problem/10773

학습 난이도: 스택 기초 응용. 상태: 로컬 테스트 완료, 온라인 채점 미확인.

양수는 기록하고 0은 최근 기록 하나를 취소한다. 스택에 넣을 때 합에 더하고 꺼낼 때 합에서 빼면 마지막 합을 다시 순회하지 않아도 된다.
0이 주어질 때 취소할 값이 존재한다는 문제 조건을 사용한다.
시간 O(N), 저장 공간 O(N). 합은 long으로 관리한다.

테스트: [3,0,4,0] → 0, [1,2,0,3] → 4, [7] → 7.
학습 포인트: 취소 시 마지막 값만 제거하며, 누적 합도 함께 복구한다.
