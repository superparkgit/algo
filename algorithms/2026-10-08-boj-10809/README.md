# 백준 10809 · 알파벳 찾기

- 문제: https://www.acmicpc.net/problem/10809
- 학습 난이도: 기초 문자열·배열
- 상태: Java 로컬 테스트 완료. 온라인 제출 여부 미확인.

## 직접 작성한 요약

소문자 단어에서 a부터 z까지 각 문자가 처음 등장한 위치를 출력한다. 등장하지 않은 문자는 -1로 표시한다. 위치는 0부터 시작한다.

## 풀이

26칸 배열을 -1로 초기화한다. 문자를 'a'와의 차이로 인덱스로 바꾸고, 해당 칸이 아직 -1일 때만 현재 위치를 기록한다. 같은 문자가 다시 나와도 첫 위치를 유지한다.

시간은 O(L + 26), 추가 배열 공간은 O(26)이다. L은 단어 길이다.

## 학습 포인트

- 기본값 0은 첫 위치 0과 구분되지 않으므로 미등장 상태에 -1을 사용한다.
- Arrays.fill로 배열 전체를 초기화한다.
- 첫 위치와 마지막 위치를 구하는 조건의 차이를 설명한다.

## 검증

- baekjoon: b=0, a=1, o=5 등 26개 출력 확인
- a: a=0, 나머지 -1
- zzzz: z=0으로 유지
- abcdefghijklmnopqrstuvwxyz: 0부터 25까지 출력

모두 로컬 기대 결과와 일치했다. 직접 학습 과제는 코드를 다시 작성하고 백준에 제출하는 것이다.
