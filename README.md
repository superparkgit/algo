# Python + Java 알고리즘 공부 기록

Python과 Java 문법을 함께 익히고, 매일 프로그래머스 알고리즘 문제를
두 언어로 풀어 기록하는 저장소입니다.

## 매일 진행 방식

1. 전날 복습 퀴즈
2. 오늘의 문법 설명
3. Python과 Java 비교 예제
4. 예제 문제 연습
5. 프로그래머스 문제 풀이
6. 시험(힌트 없이 진행)
7. 채점 및 오답 기록

## 문법 집중 과정

| 일차 | 학습 주제 | 시험 범위 |
|---|---|---|
| 1일차 | 변수, 자료형, 연산자, 함수 | 계산과 반환 함수 |
| 2일차 | 조건문, 반복문 | 조건 판별과 누적 계산 |
| 3일차 | 배열, 리스트, 문자열 | 순회와 문자열 처리 |
| 4일차 | 정렬, 집합, 맵, 컬렉션 | 빈도 계산과 데이터 가공 |

문법 과정이 끝나면 시간복잡도, 완전탐색, 정렬, 해시, 스택·큐,
DFS·BFS, 그리디, 동적 계획법 순으로 공부한다.

## 채점 원칙

- 매일 시험은 100점 만점이다.
- 정답 여부뿐 아니라 풀이 설명, 문법 정확성, 코드 가독성도 평가한다.
- 실행하지 않거나 검색하지 않고 답한 첫 제출만 최초 점수로 기록한다.
- 틀린 문제는 다음 날 복습하고, 3일 뒤 다시 풀어 숙달 여부를 확인한다.
- Python과 Java를 각각 평가한다.

## 파일 구조

```text
cs-study/
├── README.md
├── progress.md
├── grammar/
│   └── day01.md
└── algorithms/
    ├── README.md
    └── YYYY-MM-DD-problem-name/
        ├── README.md
        ├── solution.py
        └── Solution.java
```

- `progress.md`: 점수와 오답 누적 기록
- `grammar/`: 문법 수업, 연습문제, 시험지
- `algorithms/`: 날짜별 알고리즘 문제와 Python·Java 풀이

## 매일 알고리즘 기록 방법

1. `algorithms/날짜-문제명/` 폴더를 만든다.
2. `README.md`에 문제 링크, 핵심 조건, 풀이 아이디어, 복잡도를 기록한다.
3. `solution.py`와 `Solution.java`에 같은 문제의 풀이를 작성한다.
4. 채점 결과와 실수는 `progress.md`에 기록한다.
